\# SQL-Server-Training-Project\
\
\## فكرة المشروع\
\
مشروع لإدارة الأشخاص والأرصدة، بيسمحلك تضيف البيانات وتعرضها وتعدّلها أو تحذفها من خلال واجهة ويب بسيطة.\
\
المشروع معمول باستخدام \*\*Node.js وExpress\*\* مع قاعدة بيانات \*\*SQL Server\*\*، وده بيوضح إزاي نربط تطبيق ويب بقاعدة بيانات علائقية ونتعامل مع البيانات من خلال API باستخدام SQL Queries.\
\
\---\
\
\## أهم مميزات المشروع\
\
\- إضافة شخص جديد بالاسم والرصيد.\
\- عرض الأشخاص المسجلين في قاعدة البيانات.\
\- تعديل بيانات شخص أو حذفه.\
\- تخزين الأرصدة باستخدام أنواع بيانات رقمية مناسبة للقيم المالية.\
\- استخدام Parameterized Queries للتعامل مع البيانات وتقليل مخاطر SQL Injection.\
\- واجهة ويب بسيطة لإدارة بيانات الأشخاص.\
\
\---\
\
\## التقنيات المستخدمة\
\
\- \*\*Node.js:\*\* تشغيل التطبيق على السيرفر.\
\- \*\*Express.js:\*\* إنشاء API وتنظيم المسارات.\
\- \*\*Microsoft SQL Server:\*\* تخزين وإدارة بيانات الأشخاص.\
\- \*\*mssql:\*\* ربط Node.js بقاعدة بيانات SQL Server.\
\- \*\*msnodesqlv8:\*\* توفير الاتصال باستخدام Windows Authentication.\
\- \*\*ODBC Driver 18 for SQL Server:\*\* تمكين الاتصال بقاعدة البيانات من خلال ODBC.\
\- \*\*HTML, CSS & JavaScript:\*\* بناء واجهة المستخدم.\
\
\---\
\
\## تشغيل المشروع\
\
1\. ثبّت الحزم المطلوبة باستخدام \`npm install\`.\
2\. تأكد من تثبيت وتشغيل Microsoft SQL Server.\
3\. تأكد من تثبيت ODBC Driver 18 for SQL Server.\
4\. جهّز قاعدة بيانات SQL Server باسم \`PeopleAccounts\`.\
5\. راجع إعدادات الاتصال بقاعدة البيانات في \`config/db.js\`.\
6\. تأكد من إعداد Windows Authentication بشكل صحيح.\
7\. شغّل المشروع باستخدام أمر التشغيل الموجود في \`package.json\`.\
8\. افتح الواجهة من خلال السيرفر.\
